# Reel Studio

Raw talking-head video in → edited vertical reel out (cuts, captions, color, logos, motion graphics).
Driven by an AI coding agent: **Claude Code** or **Codex**.

ویدیوی خام بده، ریلز ادیت‌شده تحویل بگیر: برش، زیرنویس، اصلاح رنگ، لوگو و موشن‌گرافیک — با Claude Code یا Codex.

## Start

```sh
git clone <this-repo> && cd reel-studio
claude        # or: codex
```

Then say: **"I want to set up this project"** (or «می‌خوام setup این پروژه رو شروع کنم»).
The agent asks a few questions (speech-to-text, language, style) and installs everything.

After that: put a video in `videos/` and say **"edit it"**.

Needs: ffmpeg, Node 18+, Python 3.10+.
